# Qvie updates

Official Windows installers and the signed Qvie update feed. The desktop app checks this repository for new releases.

Download the latest release from the Releases page. Installers are currently unsigned Windows executables. Qvie verifies automatic updates using a pinned Ed25519 public key and SHA-512 checksums.

This repository distributes installers, not user libraries, accounts or credentials. Account authentication is handled by Firebase.
